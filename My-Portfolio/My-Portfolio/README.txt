MY PORTFOLIO WEBSITE — STARTER PROJECT

FILES
- index.html: the website content and page sections
- css/style.css: colors, layout, spacing, and responsive styling
- js/script.js: footer year and mobile navigation behavior
- images/: place your profile photo and project images here
- documents/: place your PDF resume here

HOW TO RUN
1. Extract the My-Portfolio folder.
2. Open the folder in Visual Studio Code (recommended) or another code editor.
3. Open index.html in a web browser.
4. An internet connection is currently required to load Bootstrap from its CDN.
   If you need the site to work completely offline, we can add local Bootstrap files.

CUSTOMIZE BEFORE SUBMISSION
- Replace [Your Name], [Degree / Program], [Name of School], and all other bracketed text.
- Replace the YN profile placeholder with your own initials or a profile photo.
- Add your actual projects and experience. Do not claim skills or experience you do not have.
- Add your PDF resume as documents/resume.pdf, or change the resume link in index.html.
- Replace the sample email and social links with your own details.

IMPORTANT
This is a starter template. Review and personalize every section so the live website
matches your actual background and the system documentation you will submit.
